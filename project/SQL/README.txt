Oracle Data Insert Package
==========================

Run ALL_TABLES_INSERT.sql with F5 (Run Script) in Oracle SQL Developer.
The script inserts data in foreign-key-safe order and commits after each table.

Total rows: 5497

Important:
- The script assumes the tables were created using the schema provided earlier.
- Primary-key IDs are explicitly inserted. This works with GENERATED BY DEFAULT AS IDENTITY.
- Blank CSV values are inserted as NULL.
- Dates use TO_DATE(..., 'YYYY-MM-DD').
- Relationship mapping tables not present in the CSV ZIP are not populated.
